# 儀表板頁面設計覆寫｜G6 UI V2

> 歷史紀錄：現行版面請使用同目錄 `workspace-v532.md`。以下保留改版沿革，不把舊版首頁順序、導覽與常駐限制文案重新套回目前頁面。

## G6-POL V2內網工作頁

- 「政策研判」只在授予 `viewPolicy` 時出現，集中各分析頁的政策初篩，並保留每一種資料母體。
- 以英國Green Book的ROAMEF作方法參考，依序呈現理由、目標、選項評估、監測、評估與回饋；不宣稱符合英國法定程序。
- 每項訊號至少比較維持現況、最低調整與可衡量試辦。成本、成果、比較基準或不確定性不足時，不指定首選方案。
- 「自訂分析」同樣限決策內網，提供拖曳與等價鍵盤選單，設定X軸、Y軸及圖例。
- 每張自訂圖只使用一種母體；圖表軸是描述性角色，不是因果模型的自變項與應變項。
- 薪資頁、政策排名、自訂分析及匯出只發布18–35歲青年資料；114年同口徑值尚未發布時保留缺值，不加入全年齡替代資料。

本頁覆寫 Master 中偏活動宣傳的視覺描述。G6 UI V2 採「現代公共政策戰情室」，預設服務政策決策者，研究方法與下載功能以漸進揭露保留。

## 視覺意圖

| 欄位 | G6 UI V2定義 |
|---|---|
| Subject | 新北市青年人口、勞動與薪資的政策證據介面 |
| Audience | 政府長官、承辦人、研究人員及AWS／Kiro技術評審 |
| Single job | 先辨識本期最需要關注的訊號，再追查母體、來源、公式與限制 |
| Source of truth | 三母體長格式資料、Code Book、官方來源與版本化政策規則 |
| Visual thesis | 用沉穩的深藍建立信任，以青綠表示互動；黃橘紅只表示警示或地圖強度 |
| Signature | 「資料可以支持／不能支持」的雙向政策證據卡 |

## 產品與資料邊界

- 戶籍人口、民間人口／勞動力及工作場所受僱員工三母體只並列閱讀，不相加、不互換分母。
- 行政區只適用戶籍人口資料；全市勞動與薪資不得分攤到29區。
- 薪資工作場所口徑不得描述成設籍青年所得。
- 官方行政值、官方調查估計與模型估計保留身分標籤。
- 所選年度缺值維持缺值；可另顯示最新可用年度與落後年數，但不得代填。
- 政策建議依版本化規則產生，必須同時顯示可判讀、不可判讀及尚缺資料。

資料匯出、Code Book、計算公式、PCLM／IPF／Sprague、SHA-256及更新紀錄置於次要「資料與方法」入口。桌機與手機共用漢堡選單；不再另設同層級頁籤列或浮動下載按鈕。

- 卡片圓角12–14px，使用8px間距系統。

## 地圖規則

- 人口數、占比與密度使用連續序列色階，色序為藍→淺藍→黃→橘→紅；圖例顯示共同範圍的最低值、中點及最高值，精確值另由資訊列及資料表提供。
- 變動率採以0為中心的連續發散色階，藍色表示減少、接近白色表示接近零、紅色表示增加。
- 色階版本：`G6-MAP-110-114-CONTINUOUS-V2`；同一年齡／性別使用110–114合併數值的固定共同範圍，切換年度不得重算。
- 紅色只表示數值高，不表示政策風險。
- 選取行政區使用深藍3–4px外框；hover使用較輕青綠高亮。
- 地圖快速資訊卡固定排在SVG地圖下方，不得覆蓋任何行政區或攔截地圖點擊。
- 人口密度僅使用已取得並查核的官方行政區土地面積計算。
- 地圖必須有可排序的29區資料表替代方案。

## 政策卡規則

- 狀態只有：已觸發、持續觀察、目前未觸發、無法判定。
- 每張卡固定包含資料訊號、相對位置、可以判讀、不能推論、政策問題、政策工具、主責／協辦、監測指標及尚缺資料。
- 政策建議採英國政府數位服務常見的「先摘要、後展開」結構：建議處理方向置頂，資料訊號、政策工具、主責／協辦及監測指標以摘要清單直接呈現；證據、執行條件、限制與版本規則分成獨立展開區。
- 不把所有人都需要看到的政策方向藏入折疊內容；展開區只放追溯、執行與治理細節，且不得巢狀折疊。
- 行政區政策分析以「數據呈現的趨勢」與「可以進行的措施」兩段式條列為主要閱讀路徑，資料解讀限制另以護欄區塊呈現；正文不得低於13px，主要分析文字以14px以上為原則。
- 人口規模前四分位只觸發「量能盤點」，不得直接判定服務不足。
- 只有人口、同行政區服務人次、活動場次、曝光強度及量能欄位同時存在時，才可觸發分區服務量能警示。
- 主責及協辦局處在人工核准前顯示待確認。
- 「政策行動雷達」使用排序式行動板，不使用沒有共同量尺的蜘蛛網圖。

## 薪資缺值

所選114年時必須同時顯示：

- 114年尚未發布
- 最新可用113年
- 18–35歲最新全年薪資平均60.9萬元
- 資料落後1年
- 工作場所口徑
- 官方原生或模型估計身分

113年數值只作背景，不寫入114年欄位。

## 薪資年度分析｜G6 UI V5.16

- 第一、第二象限統一使用「薪資數值長條＋年增率折線」雙Y軸；薪資左軸從0開始，年增率右軸保留0基準線。長條不直接堆數字，改由游標、鍵盤焦點、年度摘要列及資料表讀值。
- 第三象限以「平均數－中位數」絕對差額長條與差額占平均數折線並讀；資料表另列平均數、中位數、各自年增率與成長速度差。差額占平均數仍只是偏斜代理值，不得改稱正式偏態係數或所得不均。
- 第四象限以兩個年齡層的點估計線及灰色半透明方法敏感度帶比較；上下邊界以虛線標出，重疊區因透明度疊加呈深灰，兩條點估計線另以實線／虛線區分。
- 第四象限每年在兩條點估計線之間，以紅色粗體標示絕對差額；正負方向仍以資料表的「乙－甲」為準。
- 方法敏感度帶不是抽樣信賴區間；兩帶重疊只表示目前無法判定有明顯差異，不得宣稱統計上無顯著差異。
- 全年齡勞退提繳工資不在薪資前台、政策排名、自訂分析或匯出發布；年齡別官方資料若作模型輔助，須留在方法紀錄並不得直接作為政策數值。
- 114年全年總薪資一律維持尚未發布，不延伸折線、不補長條、不以前一年代填。

## 首頁、薪資篩選與政策流程｜G6 UI V5.20

- 首頁依登入權限顯示兩層入口：五個「資料分析」入口，以及政策研判、自訂分析、資料匯出三個「決策工具」入口。未授權功能不出現在公開檢視。
- 薪資頁提供18–35、18–24、25–29、30–35歲共四組青年年齡篩選；摘要、四象限及青年行業薪資矩陣同步更新。性別固定男女合計，工作場所母體不變。
- 全年齡行業×事業規模提繳工資不得因恢復篩選而改標為青年薪資。
- ROAMEF採六個可點選步驟與單一詳情區。步驟卡只顯示名稱與產出；「要回答、完成後留下、本頁怎麼支援」在選取後顯示。
- ROAMEF來源與方法界線集中於單一展開區，不使用巢狀折疊；F完成後回到R形成下一輪研判。
- 步驟控制使用語意化按鈕、`aria-pressed`、44px以上目標與明顯焦點框；窄螢幕改為兩欄並移除裝飾箭頭。

## 政策研判雙分流｜G6 UI V5.21

- 政策研判首頁先分為「行政區建議」與「新北市建議」，不在同一畫面同時呈現地圖、全部篩選器及六階段詳情。
- 行政區流程固定為：選擇29行政區 → 設定年度、年齡與性別 → 閱讀ROAMEF；地圖初始只用114年18–35歲男女合計戶籍人口協助定位，顏色不代表政策風險。
- 新北市流程固定為：設定年度、年齡與性別 → 閱讀ROAMEF。
- 行政區R階段只呈現戶籍人口、教育、婚姻、男女與據點清冊等區級證據。全市勞動、青年就業行業與工作場所薪資不得在行政區流程顯示或分攤。
- ROAMEF改為由上而下的六張連接卡片。每張卡常駐顯示一個問題、一句結論與兩個紀錄標籤；點擊後才展開證據、選項、監測、成果與下一步。
- A階段固定比較維持現況、最低調整與小規模試辦，並列優點與限制；資料不足時不指定首選方案。
- E階段把過程成果、結果成果與不利影響分開，沒有合理比較設計時只描述變化，不宣稱因果。
- 頁尾提供帶入目前範圍、年度、年齡及性別的AI問答入口；回答仍須顯示來源與不能推論的限制。
- 每一項證據提供「查看完整依據與限制」連結；點擊後由右側滑出證據視窗，顯示相符的實際趨勢／結構圖、可見數值、資料範圍、數值身分、官方來源與讀圖限制。
- 流程提供返回上一步、重新選擇分流、進度指示、鍵盤可操作SVG行政區及清單替代方案；互動目標至少44px並遵守減少動態偏好。

## 行動版導覽修正｜G6 UI V5.22

- 主選單脫離置頂列的濾鏡容器，固定於行動裝置可視視窗內。
- 選單使用動態視窗高度、觸控慣性捲動及捲動邊界，避免 iOS Safari 工具列造成底部項目無法觸及。
- 選單開啟時背景維持鎖定；選單本身仍可垂直滑動，標題列固定於選單頂端。

## AI與證據

- AI問答改為桌機右側可收合面板、手機底部面板，不以浮動按鈕遮住地圖或圖例。
- 問答上下文包含頁面、年度、年齡、性別、行政區、母體與資料版本。
- 回答必須附來源與限制；缺資料時不猜測。
- 每張圖保留「查看證據」，展開母體、年度、數值身分、方法、更新日、來源及可用性七項資料。
- 所有圖表提供可展開資料表。

## 無障礙與動態

- 一般文字對比至少4.5:1，焦點框清楚可見。
- 互動目標至少44×44px，手機以點擊取代hover。
- 行政區SVG可鍵盤聚焦並以Enter或Space選取。
- 動態150–300ms，遵守`prefers-reduced-motion`。
- 驗證375、768、1024及1440px，不得產生整頁水平捲動。
