# 新北青年政策決策工作台｜G6 UI V5.32

## 適用範圍與優先順序

本檔為現行介面規格，優先於 MASTER 與 dashboard.md 的歷史視覺描述。只規範閱讀、元件與互動，不覆寫資料母體、指標公式、初篩門檻、來源、缺值、公開／內網及下載權限。

定位是政策決策工作台。保持深藍政府識別列、可收合桌機側欄、手機抽屜、白色內容卡。沿用既有生成圖示，不加入裝飾插圖、大型漸層或發光。

## 閱讀路徑

- 首頁先呈現官方每月戶籍人口；連續月份與同月份跨年比較保留。
- 下方是五個資料入口，加上依權限顯示的政策研判、自訂分析、資料匯出。未授權者不顯示受限工具。
- 入口卡顯示簡稱、地理範圍、實際資料年度及一句問題；完整名稱、母體及細節收進小問號。
- 內頁保留完整標題，詳細期間及更新資訊可展開；不重複大型介紹。
- 圖表先看數據重點，再看圖、資料表與來源。一般分析條件標「只影響本圖」；薪資共用條件明示影響整頁。行政區維持按下套用後才更新地圖與排名。

程式對應 `app/workspace-ui.css` 的語意變數。紅／綠變動方向、地圖低到高色階、官方身分及模型區間維持原意義，不能用整體文字色蓋掉。

## 圖表與表格

- 共用 `ChartCanvas` 保留原SVG及資料，窄畫面只在圖內水平捲動，不撐寬頁面。16單位刻度的最小換算為14px；垂直數值軸在捲動時固定。橫條圖的行業文字分行，不把類別欄錯當數值軸固定；右側預留完整數字空間。
- 點選／鍵盤聚焦資料點後提供圖下數值，浮動提示使用頁面層顯示並避開視窗邊緣。
- 保留圖表資料表。寬表固定第一欄，仍可局部捲動；政策比較表維持窄版格式。
- 2000ms移動長條、點及線，2100ms後顯示資料標籤；提供更新中提示。快速重選沿用現有動畫銜接；減少動態偏好立即顯示，不延遲數值。
- 軸刻度、母體、年度、圖例不作延遲隱藏。來源及計算方式可展開，不能移除追溯資訊。

## 政策頁

- 三種狀態保留項數與選取操作；空狀態不拉長到相鄰清單高度。
- ROAMEF仍按配對卡片對齊；不更動R/O/A/M/E/F的資料、方案和判定。
- 模型上下限的文字明細預設收合，圖上範圍、提示數字和資料表仍完整。

## 匯出與抽屜

- 匯出頁只保留「主題→範圍→欄位→預覽下載」一組條件。三母體快速下載讀相同可見條件，僅在單一年、年齡、性別及地區時啟用；母體限制仍由後端執行。
- 導覽、AI問答、政策訊號、支持證據抽屜共用焦點處理。開啟時進入抽屜、Tab循環、Escape關閉、關閉後回原入口；巢狀抽屜只操作最上層。
- 手機選單保留獨立觸控捲動及安全區間距。列印時取消固定軸及圖內最小寬度。

## 驗收

檢查桌機與手機的換行、首屏密度、橫向捲動、完整數值、焦點回復、快速切換及減少動態。實際瀏覽器尚未測到的項目需列為待驗證，不能用原始碼測試宣稱真機通過。
