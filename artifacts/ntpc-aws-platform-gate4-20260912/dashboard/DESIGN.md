# Visual direction｜NTPC Youth Evidence Console

| Field | Direction |
|---|---|
| Subject | 新北市青年政策公開資料、定義治理與查核證據 |
| Audience | 青年局承辦人、資料分析與資訊人員；會議前快速查問、核對與追溯 |
| Single job | 在不混淆母體、時間與地理角色的前提下，快速回答「數字是多少、從哪裡來、能不能用」 |
| Source of truth | G5 V3.2三母體CSV、第4份政策服務輔助CSV、`data_catalog.json`與row-level lineage |
| Visual thesis | 像一份可操作的政府證據卷宗：沉穩、密度高，但每個數值都可回到來源與裁示狀態 |
| Palette | Navy `#0f2942`、blue `#0b6ea8`、paper `#f4f7f9`、ink `#10212f`、amber `#a65b00`、red `#b42318` |
| Type | 系統中文字體；標題用較粗字重，數字用等寬數字特性，不載入外部字型 |
| Layout | 首屏先呈現三項政策訊號與核心KPI；其後為地區／年齡矩陣、政策雷達、行政區地圖、政策服務輔助證據、戶籍、勞動、薪資、下載、ChatBot與方法 |
| Signature | 三母體同頁但分區、行政區只控制戶籍資料；匯出中心以必要欄位鎖定母體、時間、數值身分與可用性 |

## 政策服務輔助證據

- 第4份分析CSV不建立第四個人口母體；年度人次、據點快照與戶籍人口只並列，不直接相除。
- 地圖密度使用官方戶籍青年人口÷官方公告土地面積；紅色只代表數值高，不代表風險。
- 行政區面板列出官方青年服務據點、營運狀態與原單位量能；沒有據點不推論沒有服務。
- 服務參與／曝光強度使用人次÷活動場次，重複人次保留；行政區缺人次與場次交叉時不發布分區值。

## Pre-build critique

搜尋建議偏向鮮豔青年風格，但本產品的主要任務是行政查核，不是活動宣傳；因此保留清楚區塊與藍色層級，移除高彩裝飾。視覺重點集中在年齡軌與證據狀態，所有警示同時使用文字與色彩，避免只靠顏色傳達。

## CSV匯出中心

- 預設為研究查核版，優先保留公式、方法、不確定性、來源與QA。
- 多母體各自下載，不把不同母體合併成同一分母。
- 必要欄位不能取消；畫面用中文，內部欄位代碼只在Code Book與研究匯出中揭露。
- 手機版改為單欄，所有checkbox、radio、summary及按鈕可用鍵盤操作並有清楚焦點狀態。
