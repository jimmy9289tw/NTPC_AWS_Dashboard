# 政策研判：分類清單、多證據整合與圖表修正

日期：2026-09-08。呈現層版本：多證據整合 V1。原始資料、年齡估計、政策V7數值門檻均不更動。

## 現況診斷

- 原行政區頁只建立已觸發面向，並共用行政區總狀態；無法完整展示持續監測或資料待補議題。
- 原A的三種方案雖有主題差異，但優缺點大量共用；M主要依「維持現況／其他」兩種固定流程切換。
- ROAMEF原為3:2欄寬、靠上對齊，同列卡片底部不齊。
- 原比較圖使用HTML百分比橫條，折線圖則使用SVG，抽屜與窄畫面下有兩套不同尺寸規則。

## 多資料如何改變方案

1. 主議題的原始狀態決定「可優先盤點、持續監測或先補資料」。其他議題不能替主議題觸發介入。
2. 行政區人口變動影響固定場地或可調度服務的比較；教育、婚姻或性別另有初篩訊號時，才加入相符的可選服務與需求查核。
3. 全市把失業率年度變化、主要就業行業、平均與中位薪資差額並列；勞動／居住地行業／工作場所薪資不得拼成同一批個人的資料。
4. 全市另提供教育及婚姻結構作需求訪談分組背景，不把戶籍結構當成失業者的學歷或家庭條件。
5. 資料支持的是「值得比較的方案」，不是最佳方案或已證明有效的政策。方案清冊、名額、成本與實際需求尚未完整取得，不宣稱現行方案存在、缺席或失敗。

### 監測差異

| 議題 | 介入後重點指標例 |
| --- | --- |
| 教育程度 | 課程完成、後續就業／進修、媒合後留任 |
| 就業轉銜 | 求職媒合到職、留任、未匹配原因 |
| 行業結構 | 有效職缺核對、體驗後到職、留任 |
| 教育×婚姻 | 到場、後續參與意願；不考核結婚率 |
| 性別結構 | 各性別報名至完成比例、實際使用障礙；不以戶籍人口為服務分母 |
| 青年據點 | 轉介完成、交通時間、每服務人次成本 |
| 薪資 | 職缺匹配與工作條件、同口徑薪資發布；全市薪資不是諮詢成效 |

維持現況時，M先列既有方案資料完整度與官方背景更新；不把尚未採行的試辦指標列成已有成果。

## 可學習的官方網站

- [GOV.UK Summary list／Summary cards](https://design-system.service.gov.uk/components/summary-list/)：摘要資訊、行動入口與詳細資訊分層。清單使用語意化列表，沒有直接搬用頁面模板。
- [GOV.UK Accordion](https://design-system.service.gov.uk/components/accordion/)：細節漸進展開，主要判讀常駐顯示。
- [Magenta Book](https://www.gov.uk/government/publications/the-magenta-book/magenta-book-central-government-guidance-on-evaluation-html)：情境、多來源證據、評估與監測界線。
- [Test and Learn](https://www.gov.uk/government/publications/the-magenta-book/test-and-learn-html)：先確認假設與試辦方式，再依過程、結果及成本決定是否調整。

以上為2026-09-08查閱的方法與排版參考，不是英國政府對本系統的認證，也不是各項政策有效的實證來源。數值來源仍依每張證據圖的來源清單。
