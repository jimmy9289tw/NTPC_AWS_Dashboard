## 資料與權限維持不變

未修改資料檔、母體、指標公式、估計方法、排名、政策分類門檻、角色權限或伺服器授權。模型敏感度仍不代表統計顯著性。114年薪資缺值不以前一年取代。

快速下載只在可見條件各選單一年、青年年齡組、性別及地區時啟用，不偷偷改用頁面舊條件。行政區僅影響戶籍；核心勞動及薪資仍是全新北市、男女合計，行業資料保留原性別範圍。服務快照及多選改用主匯出流程。

## 驗證紀錄

- 正式建置通過；仍有既有大於500KB的前端區塊提醒，後續可獨立規劃拆包，這次不改載入資料邏輯。
- 完整測試190項通過（包含新增7項）：匯出條件、焦點循環、SSR圖形及表格、上下限、點估計差值、字型尺寸、標籤分行、數值軸判別、提示框、動畫、政策與權限。
- 新增／重構共用元件的限定範圍 ESLint 通過。原大型 dashboard-client 的未使用元件等既有告警未在本次全面清理。
- 全專案型別檢查仍有原有17項錯誤（舊元件分支型別與可能為undefined的政策輸入等），不宣稱全專案型別檢查通過。這次新元件與新增測試不增加錯誤。
- 瀏覽器公開模式：1366×900檢查簡稱與四象限；390×844檢查首頁和行業頁。手機頁面寬375px（含捲軸空間），沒有整頁橫向溢出；月底圖278px可視區內捲動665px圖形，垂直數值軸固定，點選顯示「110年1月，937,093人」。
- 手機選單開啟焦點落第一入口、Shift+Tab可循環到最後連結、Escape關閉後返回漢堡按鈕；AI開啟聚焦文字輸入框，Escape後回AI入口並解除背景捲動鎖定。
- 政策內網及匯出權限以既有測試帳號的伺服器／SSR測試驗證，沒有借用或繞過真實帳號登入。尚未完成真實內網帳號操作、iPhone Safari實機、螢幕閱讀器及實際列印驗收。
