# 自訂分析：座標軸可讀性修正

日期：2026-09-08。範圍：自訂分析的折線、群組長條及資料表替代方案。
本次為本機介面修改，不更新資料版、政策規則版或正式部署版本。

## 為什麼修改

原圖使用固定920像素的SVG視框，所有行政區共用同一寬度，文字隨整張圖縮小；超過10字的名稱另被省略。29區比較時無法直接辨認名稱。

## 新的閱讀方式

| 項目 | 呈現方式 |
| --- | --- |
| 地區很多 | 自動直向逐字排列完整名稱，每類至少56像素間距。 |
| 年度或其他分類 | 自動橫向換行；使用者也可選45度斜排或直向排列。 |
| X軸文字 | 16像素，不略去名稱；依文字行數增加下方留白。 |
| Y軸文字 | 水平顯示指標名稱與單位；左側刻度14像素，使用千分位。 |
| 多組長條 | 每組預留間距，不因分類變多而讓長條重疊。 |
| 窄畫面 | 只有圖表內部左右捲動，Y軸保留在左邊；另提供往左／往右按鈕。 |
| 查詢數值 | 游標、點擊或鍵盤聚焦資料點更新圖下數值列；也可用44像素高的選單指定完整類別。 |
| 圖例 | 完整名稱換行；折線以實線、虛線及顏色輔助辨識。 |
| 資料表 | 保留全部篩選後的分類，不受圖上最多8組圖例的既有限制。 |

## 資料與方法界線

- 沿用 `custom-analysis-workbench.tsx` 的來源資料、分類、母體、年齡及性別篩選；不新增估計或跨母體合併。
- 沿用原Y軸上限的取整方法與0起點；改變的是留白、標籤及捲動，不是數值或排名。
- 同一X軸比較項目中，個別分組缺值時不畫值，該分組折線在該處中斷。
- 非年度類別若使用折線，提示「連接不同類別，不代表時間趨勢」；仍可選長條圖。
- 資料身分、來源、限制、登入及匯出權限不變。
- UI/UX Pro Max用於閱讀間距、完整標籤、鍵盤替代操作；visualize-data規範用於單位、缺值、圖例與表格查核。沿用專案SVG元件，不更換圖表套件。
