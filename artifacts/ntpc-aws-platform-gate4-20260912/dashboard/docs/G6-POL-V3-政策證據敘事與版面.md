## 畫面與敘事

桌機上方R/O，下接A/M，再接E/F；窄螢幕依R、O、A、M、E、F順序單欄。每次只呈現一個政策議題，其他議題由選單切換。

1. R：已觀察到的數值、比較對象與差距；主圖只回答旁邊的判讀，不複製其他頁面的全部圖表。
2. O：建議改善方向、觀察基準與尚待建立的服務成果基準分開。沒有任意目標值、完成率或假進度。
3. A：維持現況、最低調整、小規模試辦。預設維持現況，不指定首選；可切換比較，非正式核定。
4. M：連動所選方案的期間與執行安排，指標沿用同一目標，揭露算法、來源、頻率及資料責任。
5. E：只顯示評估設計，尚未執行時不顯示成果。前後變動不等於政策因果效果。
6. F：列出續辦、調整、停止或暫緩條件；缺少結果或核定門檻時不自動判定。

以資料科學解讀順序寫作：數值及比較 → 可支持的解讀 → 未知原因 → 可討論的介入。婚姻、教育及性別結構不評斷個人好壞，不推論意願或需求。

## 圖表契約

| 議題 | 主要問題與資料 | 呈現 | 比較與限制 |
|---|---|---|---|
| 行政區人口／據點 | 同年度窗、年齡、性別的戶籍人口是否增加 | 期間折線、首末值、增幅摘要；並列原排名及據點快照說明 | 年末存量；據點115年快照不可改稱114年歷史值 |
| 教育、婚姻 | 所選族群相較全市有何差異 | 區／市直接比較條，標示百分點差距 | 同母體及分母；全市平均不是政策目標 |
| 教育×婚姻 | 大學與研究所青年有偶占比是否低於全市 | 區／市比較、差額、原模型敏感度範圍 | 分母是同年同區同年齡同性別之大學及研究所人口 |
| 性別 | 男性占青年人口比率與全市差多少 | 區／市比較 | 專看男女合計中的男性占比，明示不受性別篩選改變；不能替代服務參與性別差距 |
| 勞動 | 失業率與前一年及原五年基準相比如何 | 趨勢、年差、110–114年中位數參考線 | 分母為勞動力；全年12個月平均；尚無同性別數值時明示男女合計 |
| 行業 | 青年就業者集中在哪些行業 | 前五大行業比較及合計占比 | 居住地就業者口徑；不直接推論缺工、薪資或職業 |
| 薪資 | 同年度平均數與中位數差距 | 直接比較兩值、差額及敏感度範圍 | 工作場所母體、男女合計；114缺值，113只作明示背景 |

每圖保留圖表資料表及右側證據視窗，包含母體、年度、數值身分、方法、資料包生成時間、來源及可用性。更新時間不冒充官方發布日。

依使用者本次追加裁示，呈現用差額改以畫面已四捨五入的數值計算：平溪有偶占比10.72%，全市18.58%，顯示差距18.58−10.72＝7.86個百分點。占比採兩位小數，薪資差額採一位小數，前五大行業合計採各行顯示值相加。原始資料、年齡估計、排名與觸發門檻仍使用原精度，呈現用差額不得反寫覆蓋統計資料。模型包絡不等於信賴區間，重疊不代表完成「無顯著差異」檢定。

## 方案草案校準

新版政策頁採簡報草案：巡迴服務6個月，每3個月至少2場；青年交流6個月2場；教育／技能每6個月1梯次。頻率與權責皆待核定。

舊引擎回傳的行動文字含「每月至少2場」及「4場交流」，本次不改舊引擎；新的敘事轉接層以修正版簡報提供政策頁的A/M方案，避免改動既有計算與觸發規則。將來其他舊政策元件若再次啟用，須同步核對其試辦文字。

性別結構只提供需求查核線索；未取得參與資料時，不能聲稱已觀察到服務觸及不平等，也不直接啟動以該差距為由的A/B測試。
