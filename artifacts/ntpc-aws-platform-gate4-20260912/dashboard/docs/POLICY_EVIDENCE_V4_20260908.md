# 政策研判證據比較改版｜2026-09-08

本版：G6 UI V5.26／G6-POL V3.3。現行行政區初篩V7的母體、估計方法與觸發門檻不變。這是介面與證據整理改版，不是重新估計人口或政策成效。

## 圖表與資料契約

- 問題：同一年齡、性別，該行政區相較新北市的數值為何？前一年到本年如何變化？
- 呈現：X軸為所選年度之前一年、所選年度；新北市與行政區各一根長條，Y軸為實際指標及單位。只有兩個觀察期，採群組長條而非推測月度趨勢。
- 人口、密度、年變化率、五類教育與四類婚姻，都沿用既有資料與公式。人數使用原人口值；密度使用人口除官方土地面積；年增率使用相鄰年末人口。
- 新北市的人口與密度是全市值，不是29區的簡單平均。比較的是同年齡性別，並非全齡市人口。
- 右側視窗與R使用同一個圖表元件。刻度、座標尺寸和提示框與人口四象限共用基礎元件；數值範圍依資料決定，百分比上限進位至十位。
- 長條從0起算；年增率有負值時保留負值範圍與0線。灰色誤差線呈現模型敏感度上下限，不是抽樣信賴區間。
- 圖例文字、鍵盤聚焦／點擊讀值、窄畫面圖內捲動、可展開資料表均保留。所有表格限制在所在卡片之內。

## 婚姻與教育交叉分析

婚姻狀態含未婚、有偶、離婚或終止結婚、喪偶；教育含國中及以下、高中職、專科、大學、研究所，共20個交叉比較，另保留原決策樹使用的「大學及研究所有偶占比」。

比例公式：該教育程度且屬所選婚姻狀態人口 ÷ 同年、同區、同年齡、同性別的該教育程度總人口 × 100%。使用已取得的真實交叉表換算結果，不將兩份邊際占比相乘。25–29歲使用原生年齡帶，其餘沿用PCLM＋IPF估計。上下限沿用人口敏感度包絡：分子下限／分母上限及分子上限／分母下限；占比上限不超過100%。

例：114年淡水區30–35歲合計、國中及以下的離婚或終止結婚占比為14.76%，全市15.79%，以展示值相減低1.03個百分點；113年分別為14.76%、15.25%。這個例子不支持「淡水該群體高於全市」的敘述。此數值是模型估計；教育與婚姻的關聯不等於因果。

新交叉比較不自動改寫優先盤點規則。現行婚姻主分支仍按有偶占比，教育×婚姻主分支仍按大學及研究所有偶占比分類；分流流程圖逐步呈現條件。離婚與喪偶等指標可另選讀圖及參考服務選項，並非新增已核定政策警示。

## ROAMEF內容調整

- 分類原因：逐條列數值、排名及名次變化，點擊開右側比較圖。
- R：事實摘要、可選比較指標、圖表、資料表、原規則流程圖。
- O：基準與差距、跨議題證據、服務改善方向、明確對象。試辦草案統一為6個月2場，名額與實際日期另訂。
- A：七類區級資料均可開圖；提供可選活動及官方案例連結。經費試算、分項檢核與舊優缺點區塊退出此頁，原經費程式及測試保留作參考。
- M：依活動形式切換追蹤項目，保留建議主責／協辦及分工待確認。
- E：列建議評估KPI、公式及比較設計，不偽造已執行結果。
- F：續辦、調整或改採其他方式的準則，以及「未來可整理之資訊」。

## 建議紀錄欄位與公式

活動代碼、日期、去識別化參與代碼、報名／到場、年齡組、性別（含未填）、服務主題、轉介案件、有效問卷、滿意度、後續追蹤。

1. 每場到場率＝有效報名者中實際到場人數／有效報名人數×100%。現場報名另列。
2. 服務人次＝各場到場人數加總；實際人數另按參與代碼去重。
3. 各性別占比＝各性別到場人次／全體到場人次×100%；未填／其他分列。
4. 滿意比例＝5分量表4或5分答卷／該題有效答卷×100%；另列問卷回收率。
5. 依方案追蹤轉介完成、資源使用、職涯行動完成或再次參與意願，各自列出分子、分母與回覆率。

上述KPI為本計畫建議設計，不宣稱是外部案例的官方績效指標。分母0顯示無有效分母；沒有活動紀錄不填0。
