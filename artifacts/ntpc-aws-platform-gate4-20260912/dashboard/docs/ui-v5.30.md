## 差距與分母

差距＝畫面右側點估計－畫面左側點估計。使用與畫面相同精度的四捨五入數值：人數0位、萬元1位，其他指標2位。百分比的相減單位為「個百分點」，不是百分比成長率。例如八里區113年有偶占比19.19%，新北市16.33%，差距為＋2.86個百分點；114年為18.96%－15.81%＝＋3.15個百分點。

教育×婚姻每一根柱＝該地區、該年度、該年齡、該性別、該學歷及該婚姻狀態人口÷同條件該學歷總人口×100%。新北市與行政區分別使用自己的分母；不將兩地人口混合，也不相乘教育及婚姻邊際比率。資料取自既有聯合交叉資料的cityPct／districtPct及各自上下限。

括號保留額外上方空間，位於兩柱及其上限之上。模型上下限仍呈現在圖與表格中；括號只表示點估計差距，不作顯著性檢定，不改變原有政策觸發規則。

## 月人口模式

- 連續月份：110年1月至114年12月共60個官方月底存量，保留月增率、同月年增率及首末期變動。
- 同月份：例如選6月，呈現110、111、112、113、114年6月底五個觀測值。指標卡呈現最新該月人口、首末年同月變動、相對前一年同月的增減人數及年增率。
- 人數增減＝本年同月底人口－前一年同月底人口；同月年增率＝人數增減÷前一年同月底人口×100%。缺前一年或分母為零時保留缺值。
- 模式切換只篩選現有官方月資料，不新增推估，不加總月底存量。Y軸沿用既有月人口尺度；期間標題與資料表依所選月份更新。
- 新北市114年12月18–35歲合計仍為845,938人。資料來源、API及每日審視頻率未變。
