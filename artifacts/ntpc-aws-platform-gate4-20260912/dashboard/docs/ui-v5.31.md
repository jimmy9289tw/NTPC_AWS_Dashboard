# G6 UI V5.31：行業初篩條件與支持證據

日期：2026-09-08。政策介面：G6-POL V3.6。使用者已確認commit、push及部署；本次合併V5.30與V5.31修改，實際發布結果以部署回報為準。

## 任務與範圍

將行業初篩的整段文字改成三個編號條件，逐項列出實際數值、符合／未符合／資料不足及支持圖表。主規則以「或」連接；年齡差距單列補充。不修改來源資料、三母體、模型、門檻、角色權限或資料匯出權限。

沿用UI排版與資料視覺化技能：原卡片、原圖表元件、文字及圖示並用、可操作的證據連結、兩秒位置過渡與收合資料表。此次沒有新增圖片、外部服務或套件。

## 分類與圖表契約

| 條件 | 判斷所用資料 | 對應證據 |
| --- | --- | --- |
| 主要行業占比連續三年同向，累計至少1個百分點 | 固定所選年度占比最高的行業，比較所選年、前一年、前兩年；嚴格連升或連降 | 三年折線圖、模型上下限、兩段年變動及末年減首年資料表 |
| 前五大行業集中度增加至少1個百分點 | 每年依所選年齡及性別，將19類占比重新排名後加總當年前五名 | 兩年合計占比長條圖、差距括號、各年前五名與計算精度資料表 |
| 男女行業占比差距擴大至少1個百分點 | 同一主要行業、同一年齡；每年先計算男性與女性占比的絕對差，再比較兩年的差距 | 兩年絕對差長條圖、年變動括號、男性與女性原占比計算依據 |
| 年齡差距至少3個百分點（補充） | 同年同一行業，18–24／25–29／30–35歲，男女合計，最高減最低 | 三年齡長條圖與上下限；放入補充收合區，不單獨觸發 |

母體為平常居住於新北市的青年就業者，不是設籍青年或在新北市工作的所有受僱者。條件3每個性別以同性別就業者為分母，與人數差距不同；即使頁面選男或女，此條件仍需男女兩組資料。年齡補充沿用男女合計口徑，圖上明列。

policy-industry-input.ts為原分類與圖表共用的資料選取器，從resident-employment-industry.json讀取現有資料。evaluateIndustryPolicyConditions從原引擎抽出，不改算式。所有60組年度×年齡×性別皆與獨立保留的舊版公式核對。連續年度缺值不補0、不跳過缺年。

圖中年變動依顯示到小數點後2位的值相減，以免61.64%減至61.19%卻寫成減少0.44個百分點。分類門檻仍用原精度；若四捨五入會讓門檻看似跨過，說明額外列6位小數的判斷值。來源明細保留原計算精度。前五名的合計不是五個已四捨五入比例再相加。模型範圍仍是敏感度，不宣稱統計顯著或缺工。

## 截圖案例重現

113年、18–24歲、男女合計，主要行業為批發及零售業：

1. 三年占比24.12% → 24.47% → 23.33%，未連續同向，未符合。
2. 前五大集中度70.92% → 69.54%，減少1.38個百分點，未符合。
3. 男女占比差距0.73 → 3.62個百分點，擴大2.89個百分點，符合。
4. 三個年齡層差距約5.04個百分點，僅為補充。

因此是第三項觸發，主畫面預設呈現該項證據，而非只顯示23.33%的當年行業排名圖。分類原因、R、O及右側視窗均可逐項查看對應圖表。

## A至F的狀態分流

以所選議題本身的分類決定，不能因其他議題優先而替本議題啟動試辦：

- 優先盤點：保留四種方案比較，選取後更新目標、追蹤指標及既有試辦草案。
- 持續監測：A改為「現行措施與備選工具」，主安排為維持現行措施；四種工具僅以收合參考清單呈現，不再自動選中其中一案。O、M、E、F與AI脈絡不帶入六個月兩場試辦。
- 資料待補：先整理同條件資料、來源與待補清單；更新資料後重新分類。

112年25–29歲男女合計仍為0項優先盤點、4項持續監測。行業頁不再出現試辦單選項或固定兩場執行時間表。青年據點連結維持在M；不改其清冊快照、地址或服務數據。
