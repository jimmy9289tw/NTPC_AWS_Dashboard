## 就業占比比較口徑

本圖呈現的是勞動力中就業占比＝就業人口÷勞動力人口×100%，不是以民間人口作分母的就業人口比率。年度比較使用顯示至小數點後兩位的當年占比－前一年占比，單位為「個百分點」。例如94.44%比94.43%增加0.01個百分點，而非增加0.01%。110年沒有本圖前一年資料時明列「無前期資料」，不當作零變化。這次未改原始比率公式。

### CSV行為

- 可用條件由主題控制，伺服器再次檢核；不將不支援的行政區或女性薪資悄悄替換成全市合計。
- 年度、年齡、性別與行政區各自分列。18–35與子年齡組、全市與行政區、合計與男女資料不可重複加總。
- 月份、交叉表兩個分類、據點名稱及地址等主題識別欄位不可移除，避免下載後無法區分紀錄。
- 每次最多15,000列，超出則請分年度或行政區下載；不默默截斷。
- 預覽顯示總列數、有值列數、缺值列數與前8列；下載以同一查詢條件產生全數資料。
- 篩選變更會取消舊預覽請求；舊結果不能覆蓋新條件。下載時暫停修改控制項。
- 薪資110–113年×四組年齡×平均數／中位數＝32列；114年缺值不以前一年代填。
- UTF-8 BOM、中文表頭、CSV跳脫與試算表公式注入防護保留。Code Book 1.1.0共34欄。
- 既有決策角色驗證保留於API；一般檢視者與未登入者無法下載。未變更白名單或Google登入設定。

## 動畫與可及性

使用者指定兩秒過渡。UI/UX Pro Max的層級、可讀性及減少動態原則用於提示浮層與匯出步驟；沿用現有配色與元件，不另建模板。

動畫只處理畫面幾何位置，不將動畫中間高度寫成新統計數據。文字、提示及匯出仍使用確定的目標數值。缺值導致路徑拓樸不同時不跨缺值補畫連線；初次載入直接呈現數值。尊重prefers-reduced-motion並清理動畫及事件監聽。圖表資料表及鍵盤操作保留。
