# 各分析頁資料敘述調整｜G6 UI V5.28

更新日期：2026-09-08。此版為本地修改；本次沒有 commit、push 或部署。既有 V5.27 政策頁修改一併保留，政策頁版仍為 G6-POL V3.4。

## 調整原則

以政策研判頁的事實陳述方式整理其他頁面：先列實際數值，再列相同篩選條件下的比較結果，並保留支持圖表。公開分析頁不加入私人政策方案。

UI/UX Pro Max 用於資訊層級與漸進揭露：沿用原有設計系統，摘要正文16px、標籤14px、12px圓角，說明區可用鍵盤展開且有明顯焦點框。不新增裝飾圖、套件或模型。

## 追加：篩選後圖表動態更新

- 共用 app/chart-transition.ts：15個現行圖表元件於資料或條件變更後，以250毫秒透明度漸入呈現新圖。涵蓋折線、雙軸長條、組成圖、教育×婚姻、勞動生命階段、薪資點估計與上下限、行業矩陣、自訂分析及政策證據圖。
- 原有行政區地圖保留480毫秒連續fill色彩轉換，不重新掛載地圖，不改門檻或比例尺。
- 動態key只包含圖中資料與篩選條件，不包含hover、焦點或提示框狀態。快速重選會取消上一段動畫；不排隊播放。
- 不重新建立圖表DOM，保留捲動位置與鍵盤焦點；不移動座標軸或改變容器高度。只改整圖透明度，不從零計數、不插值模型數字，不讓舊值與新條件混用。
- 系統開啟「減少動態效果」時直接顯示；播放中切換也會停止動畫。不支援Web Animations API時正常顯示靜態圖。
- 月資料及教育×婚姻非同步載入完成時同樣漸入；資料未到前保留既有載入／缺值狀態。

## 敘述生成方式

- 共用純函式位於 app/data-reading.ts；呈現元件為 app/data-reading-summary.tsx。
- 每張圖直接傳入自己的篩選後資料；不從另一圖表的外部篩選狀態取值，不回寫資料。
- 年度摘要明列最新可用年度，及圖中最早可比年度。不把隔年的缺口稱為「與去年相比」，也不把首尾差異寫成「逐年上升」。
- 先以與圖表相同的 Intl.NumberFormat 精度四捨五入，再相減。人數整數、薪資一位、比率兩位；百分比水準的差異用「個百分點」。
- 最高值及同值並列以相同顯示精度判定。最高只描述數值，不表示政策需求、統計顯著或風險。
- null、undefined、NaN不是零。114年青年薪資仍缺值；摘要寫出「114年尚無資料；最新可用為113年」。
- 自訂圖只摘要畫出的分類，資料表模式則摘要完整篩選結果，不把被圖表截去的系列寫成圖中結果。

- 官方25–29歲薪資與其他年齡模型值的身分標記不變；沒有方法上下限的原生值不捏造區間。
