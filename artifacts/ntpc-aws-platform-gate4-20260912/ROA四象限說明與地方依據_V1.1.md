# ROA 四象限說明與地方依據

AWS網站版本仍為V1.0。本次說明與呈現版為V1.1；ROA-RULES-V1-DRAFT的門檻、母體及計算公式不變。

## 為什麼有些條件沒有單一象限？

| 狀況 | 顯示方式 | 保留的資訊 |
| --- | --- | --- |
| X、Y完整範圍均在各自門檻同側 | 確定本次規則位置 | 數值、變化、比較基準、概念方向 |
| 數值完整，但X或Y範圍跨過門檻 | 數值可比較，象限尚未固定 | 點估計參考位置使用虛線，逐軸說明上下限 |
| 缺前一年或完整比較基準 | 比較資料未齊 | 當年已知值、缺少的年份或地區 |
| 115年據點快照對110–114年人口 | 期間不同 | 據點位置及官方連結，不作當年象限Y值 |
| 114年青年薪資 | 尚無同口徑值 | 提示選擇110–113年，不借全年齡薪資 |
| 教育×婚姻仍在載入 | 載入中 | 不把載入等待當作缺值或估計跨界 |

X年度變化的範圍沿用既有公式：當年下限減前一年上限，至當年上限減前一年下限；人口及薪資年增率依原百分比公式。Y與有範圍的比較基準比對時，也沿用上下限端點組合檢查。這是保守的敏感度包絡，不是95%信賴區間，不包含兩期與兩軸的相關結構。重疊不能直接轉述成「統計上無顯著差異」。

例如：淡水區113年30–35歲合計有偶占比35.60%，比112年下降0.56個百分點，但變化包絡為−1.73至+0.38個百分點，跨過X的0門檻。Y仍高於29區中位數32.71%。因此只看點估計是左上，考量包絡可能在左上或右上；保留比較，不指定唯一分級。

## 地方提案如何產生

1. 使用所選年度、行政區、年齡、性別、教育及婚姻類別的已發布數值。
2. 人口主題同時比較全市同族群年增率；18–35歲另列三年齡帶人數差。密度影響服務配置方式，但不代替街廓擁擠資料。
3. 列冊青年據點提供位置與官方來源。115年快照始終標示115年，零列冊不推成服務不足。
4. 引入已查核的LSF行政區背景，不加入四象限計分。出生率保留全年齡分母；租金保留11503期、租金補貼有效租約樣本，不能計算青年租金負擔率。
5. 淡水另有官方交通與步道案例。已完工工程只作既有基礎；後續提案是銜接路徑，不聲稱未改善。人口增加不等於青年通勤者或家長增加。
6. 未婚用自願興趣交流；有偶用家庭生活資訊；離婚用生活調適、法律及租屋資訊；喪偶用陪伴及心理支持。教育分入門實作與跨領域專題；全市就業、行業及薪資各有不同問題，不套給行政區。
7. 版面先顯示值得確認的痛點、可做事項與三個主要依據，其餘放在展開區。概念提案不是已證實存在的服務缺口。
