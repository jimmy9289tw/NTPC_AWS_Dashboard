# ADR-001｜定義衝突與青年年齡邊界

- 狀態：Accepted
- 日期：2026-08-15
- 決策來源：G3-DEC-03

## 決策

核心青年為 18–35 歲，僅由單一年齡或邊界完全一致的三組資料加總。跨越 18 或 35 邊界的來源群組不做比例拆分。定義比較順序為：法源／政策目的、母體、年齡、地理角色、時間語意、單位、分類版本、計算公式。

## 衝突狀態

- `EXACT`：全部關鍵定義一致，可直接比較。
- `CROSSWALK_REQUIRED`：存在可驗證且無損的版本對照；須保存對照表版本。
- `PARTIAL_OR_CONFLICT`：只有部分重疊或不可拆分；並列而不合併。
- `PENDING_HUMAN_DECISION`：母體、地理角色、單位、測量型態或正式指標解讀受影響；阻擋發布。

## 理由

人數可加總不代表百分比、率或平均值可拆分；用年數比例推估會隱含年齡內均勻分布，且無法恢復正確分母。保留來源原始分組並交人工裁示，才能維持行政證據的可查核性。
