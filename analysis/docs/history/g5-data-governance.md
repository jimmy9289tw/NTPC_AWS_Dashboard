# 新北市青年資料 G5 治理規則

## 不可破壞的統計邊界

1. 戶籍人口母體、民間人口及勞動市場母體、受僱員工薪資母體必須分開儲存、查詢與計算。
2. 不得以戶籍人口作失業率、勞參率或就業人口比率的分母。
3. 不得把工作場所薪資解讀為新北市戶籍青年的薪資。
4. 行政區選取只影響人口、戶籍教育、婚姻及性別；勞動與薪資維持新北市整體。
5. 25–29歲優先使用官方原生年齡帶；含18、19或35歲的類別值須標示估計方法。
6. 年度勞動值是全年12個月平均；人口年度值是12月31日存量；不得互稱或製造月值。
7. 薪資中位數不得由各組中位數加權平均；缺個體分布或頻數時標為不可發布。

## 發布資料

- `01_戶籍人口母體_長格式.csv`
- `02_民間人口與勞動市場母體_長格式.csv`
- `03_受僱員工薪資母體_長格式.csv`
- `data_catalog.json` 是唯一正式版本指標；候選檔未通過機器與人工 Gate 不得被讀取。

## 年份與更新

- 預設同年度檢視。
- 顯示年度為 `currentRocYear - 5` 至 `currentRocYear - 1`。
- 每日09:15（Asia/Taipei）審視來源；來源未變時寫 `NO_CHANGE`，不重算、不覆寫。
- 網頁更新日不得取代資料年度。

## 前端與問答

- 主要介面、圖例、坐標軸與ChatBot答案只用繁體中文或阿拉伯數字；內部代號只留在CSV、API與方法抽屜。
- 模型估計必須顯示「估計」、方法、敏感度及來源；方法包絡不是信賴區間。
- 圖表必須有鍵盤操作、文字摘要與資料表替代；不得只用顏色表達官方／估計／缺值。
- ChatBot只讀published層，使用參數化 allowlist 查詢；查無資料時明確拒答，不猜測或跨年靜默替代。

## 程式與AWS

- `agentcore/agentcore.json` 等設定檔是來源真值；不得手動修改 `agentcore/cdk` 生成目錄。
- 本階段只執行本地資料處理、前端、唯讀工具契約與測試；未修改IaC時，不要求執行IaC synth。
- 每次變更至少執行與變更範圍相符的 schema validation、pytest、前端 lint/build/test 或資料QA。
- 未取得正式部署裁示時，不得執行 `agentcore deploy`、`cdk deploy` 或 production S3 寫入。

## 目前執行邊界（G8 Kiro本地實作交接）

- Kiro開始工作前，必須先閱讀 `07_AWS與Kiro/Kiro本地實作交接流程與驗證SOP_V1.0.docx` 與 `12_AWS_Kiro_實作檔案/KIRO規格/G8_Kiro本地實作任務提示.md`。
- AWS IaC、AgentCore及排程檔可作為未來架構參考，但本階段不得登入AWS Console、不得建立雲端資源、不得寫入AWS正式資料層。
- CostCenter、預算、通知信箱、保存期與dev部署授權屬未來部署Gate，不是本地實作的前置阻擋。
- 本地實作完成的判定，以資料契約、前端測試、問答治理測試、人工查核表及可重現交付紀錄為準。
