資料夾：05_年齡轉換與統計方法

主要用途
將不同政府年齡區間轉換為18–24、25–29、30–35及18–35歲的正式方法與重現程式。

使用方式
1. 先閱讀資料包根目錄的 TOC.txt。
2. 數值必須同時保留「母體、年度／月份、地理範圍、年齡範圍、性別、數值身分、來源及方法」。
3. 官方行政精確值、官方調查估計值、模型估計值不得混稱；儀表板應顯示資料身分。
4. 不同母體可在同一頁比較，但不可直接相加、合併分母或推論為同一群人。

更新與查核
- 每日審視一次來源是否更新。
- 預設顯示（更新年份－5）至（更新年份－1）的年度資料。
- 新資料須先進入原始層，再經驗證、方法轉換與發布層；不得直接覆寫已發布檔。
- 發現定義或數值衝突時，先停止發布該指標，記錄來源差異並交由人工裁示。
