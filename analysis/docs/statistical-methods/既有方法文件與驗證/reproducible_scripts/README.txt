資料夾：05_年齡轉換與統計方法\reproducible_scripts

檔案清冊重建
- rebuild_file_manifest.ps1：在資料包內容更新完成後，重建根目錄FILE_MANIFEST_SHA256.csv；清冊排除自身，記錄相對路徑、檔案大小與SHA-256。
- 執行方式：於PowerShell執行 `./rebuild_file_manifest.ps1`；預設自動定位資料包根目錄。
- validate_export_schemas.py：不依賴外部套件，檢查匯出request／manifest宣告JSON Schema Draft 2020-12、根契約結構，並以13個必要欄位的request及manifest範例執行本規格使用到的關鍵字驗證。
- build_monthly_population_data.py：讀取ODRP014月快照，直接加總18–35歲單一年齡並驗證性別、年齡組與29區總和。
- build_resident_employment_industry_data.py：讀取110–114年表33，產製行業人數與同性別占比並檢查官方四捨五入誤差。
- update_g6_ui_v2_data_package.py：將60份月人口、5份表33、儀表板JSON、程式與QA同步至R2資料包。
- build_g5_source_manifest.py：重建完整來源清冊，包含新增65份官方原始檔與2份儀表板衍生輸出。

主要用途
可重跑的 Sprague、PCLM、資料建置、婚姻處理與驗證程式。

使用方式
1. 先閱讀資料包根目錄的 TOC.txt。
2. 數值必須同時保留「母體、年度／月份、地理範圍、年齡範圍、性別、數值身分、來源及方法」。
3. 官方行政精確值、官方調查估計值、模型估計值不得混稱；儀表板應顯示資料身分。
4. 不同母體可在同一頁比較，但不可直接相加、合併分母或推論為同一群人。

薪資平均數與中位數
- 110–113年採4年度×4年齡組×2統計量，共32列且均有數值；114年維持尚未發布。
- 25–29歲平均數與中位數為官方表6原生調查統計。
- 18–24、30–35與18–35歲平均數採官方薪資錨定與PCLM輔助年齡輪廓估計。
- 非25–29歲中位數採官方寬年齡帶形狀轉移與對數常態混合分布估計；敏感度上下界不是信賴區間。
- 取得個體薪資微資料與權數後，應以加權經驗分布第50百分位重新驗證模型中位數。

更新與查核
- 每日審視一次來源是否更新。
- 預設顯示（更新年份－5）至（更新年份－1）的年度資料。
- 新資料須先進入原始層，再經驗證、方法轉換與發布層；不得直接覆寫已發布檔。
- 發現定義或數值衝突時，先停止發布該指標，記錄來源差異並交由人工裁示。
