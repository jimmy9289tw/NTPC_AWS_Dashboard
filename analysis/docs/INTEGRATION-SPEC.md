# 公開資料介接規格 V1.0

## 1. 適用範圍

本規格適用於新北市青年政策公開資料 AI 系統。所有資料必須先登錄來源代號、官方頁面、介接方式、資料粒度、母體、地理角色、單位、更新頻率與限制，才能進入正式指標流程。

## 2. 介接類型

| 類型 | 適用來源 | 取用方式 | 必留證據 | 失敗處理 |
|---|---|---|---|---|
| `http_json_paginated` | `MOI-POP1Y` | 依民國年月與頁碼逐頁呼叫戶政司 JSON API | 請求樣板、期別、頁數、原始 JSON、SHA-256、列數、擷取時間 | 重試後仍失敗即停止該次正式產製 |
| `http_json` | `NTPC-POP`、`NTPC-UNEMP`、`NTPC-EMPSTR`、`NTPC-EDU15P` | 呼叫新北市資料開放平臺資料集 JSON 端點 | 官方資料集頁、實際 API URL、原始 JSON、SHA-256、列數、擷取時間 | 回應非 JSON、空資料或欄位異動即停止 |
| `http_xlsx` | `STAT-WAGE-EDU`、`STAT-WAGE-LOC` | 從主計總處官方頁面對應附件下載 XLSX，再依工作表及列欄選擇器讀取 | 官方發布頁、附件 URL、原始 XLSX、工作表、選擇器、SHA-256、擷取時間 | 檔頭、工作表、標籤或欄位不符即停止 |
| `manual_export` | `OAS-POP` | 人工設定查詢條件並匯出 | 查詢條件、下載頁截圖、原檔名、原檔、擷取時間、SHA-256、覆核人 | 證據未齊標記 `PENDING_HUMAN_REVIEW`，不得發布 |
| `ocr_optional` | `OCR-DOC` | 無結構掃描件優先 Amazon Textract，本地以 Tesseract 備援 | 頁碼、區塊、信心分數、原圖、人工逐欄核對紀錄 | 數值欄未覆核不得進入正式指標 |

## 3. 共通下載規則

1. 官方來源優先，來源網域限於登錄清冊。
2. 逾時 30 秒；最多 3 次重試；退避 1、3、9 秒。
3. 原始檔採版本化保存，不覆蓋前次快照。
4. 每個檔案計算 SHA-256，保存 bytes、列數、擷取時間與 URL。
5. `failClosed=true`：必要來源取得、格式或欄位驗證失敗，不產製新的正式指標。
6. 下載成功不代表定義相容；仍須通過母體、年齡、地理、期間、單位與公式檢查。

## 4. 標準處理鏈

`來源登錄 → 擷取 → 原始快照 → 格式驗證 → 欄位正規化 → 定義比對 → 衝突分流 → 指標計算 → 回測／品質檢查 → 人工發布 Gate → 儀表板／AI 問答`

每次執行建立唯一 `runId`。儀表板只讀取已通過計算的 curated JSON；AI 回答必須帶出來源、期間、母體、地理角色與限制。

## 5. 定義衝突規則

| 檢查面向 | 可直接比較條件 | 衝突範例 | 處理方式 |
|---|---|---|---|
| 年齡 | 邊界完全一致或有單一年齡 | 來源僅有 15–24，需求為 18–24 | 不按年數比例拆分；標記 `PARTIAL_OR_CONFLICT` |
| 母體 | 統計母體一致 | 戶籍人口與受僱員工 | 不合併；分面呈現並註明母體 |
| 地理角色 | 同為居住地或同為工作場所 | 新北戶籍人口與新北工作場所薪資 | 不推論為同一批人；並列描述 |
| 時間 | 期別與年度語意一致 | 月底人口與全年薪資 | 明示不同觀察期，不計算直接比率 |
| 單位／統計量 | 單位、分母、平均／中位一致 | 平均薪資與中位薪資 | 分開呈現，不互換 |
| 分類版本 | 有無損且留版本的對照表 | 教育程度分類改版 | 建立 crosswalk；無法無損則交人工裁示 |

## 6. AWS 問答介接

目標鏈為：`私人儀表板 → /api/ask → API Gateway（API key）→ Lambda → Bedrock AgentCore InvokeHarness → CloudWatch`。前端不得持有 AWS 憑證或 API key；Lambda 只允許呼叫既有 Harness ARN。外部傳入問題須驗證長度與型態，並限制工具清單。

目前 Harness 已在 `us-west-2`；API bridge 程式與 CloudFormation/SAM 範本已備妥，但尚未實際部署。Owner、CostCenter、預算告警、API key 輪替與日誌保存期未核定前，儀表板維持 `LOCAL_EVIDENCE_FALLBACK`，不得標示為 AWS 即時問答。

## 7. 維運與異常

- API 欄位異動：保留失敗 manifest，不覆蓋最新成功快照，開立欄位對照查核。
- 官方修訂：以新 `runId` 保存，不刪除舊版；在發布說明記載差異。
- 跨來源不一致：保留雙方原值、定義與版本，先判斷是否可建立無損對照；否則交具名裁示。
- 來源暫停：儀表板顯示最後成功期別與資料齡；不得以模型補值。
- 回復：清除 bridge secrets 可回到本地證據模式，不必刪除既有 Harness。
