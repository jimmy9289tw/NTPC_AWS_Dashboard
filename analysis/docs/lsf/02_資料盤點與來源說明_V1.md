## 01–08介接方式

延續使用者指定`09_發布資料包`的欄位體系，新增`11_生活條件與公共服務_長格式.csv`（42欄、793列）。資料夾內的檔案編號不是新增第11種母體。

- 01、02、03三母體與06服務輔助原樣保留。
- 04來源主檔：增加1個年報來源與4個租屋型態查詢來源。
- 05資料列來源關聯：增加793個record_id的對應紀錄。
- 07整合狀態：記錄新背景層，說明不灌入三母體。
- 08介接規則：列明地區代碼、各自期間、允許用途及不可推論的事項。
- 09、10既有月度與行業檔、原code_book及catalog保留。新`lsf-catalog.json`獨立描述LSF發布層，不把原catalog偽裝成已更新外部資料。

原始快照在`data/lsf/raw/20260912`，處理輸出在`data/lsf/published`。來源快照欄位為儲存庫相對路徑，完整原始碼資料夾可直接解析；發布包旁亦附同一路徑的來源鏡像。

新背景列的`age_band=ALL_AGES`與`sex_code=ALL`表示來源未提供青年及性別交叉，不能與青年篩選鍵直接inner join。`universe_code=AUXILIARY_CONTEXT`為租約背景標籤，不是第四個可與三母體互換的個人母體。空白`value`配合UNAVAILABLE及原因讀取；加減式指標不使用numerator/denominator冒充除法。

## 更新流程

原始來源 → 快照與擷取證明 → 期間與欄位檢查 → 42欄長格式 → 來源關聯 → 數值與缺值檢查 → 決策樹案例測試 → 視覺確認 → 新版發布。

本次是一次性快照，不是已啟動每日自動更新。離線重建用`lsf_build.py`；網路更新用`lsf_fetch.py`另建新日期快照後才重建。原快照不覆寫，缺期別或schema不符須停止該來源並保留前版。
