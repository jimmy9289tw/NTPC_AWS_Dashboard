- [ ] **HR-AGE-01｜核心年齡（阻擋）**：18–35 只由單一年齡精確加總；15–17 與 36–40 未進入核心總數。

- [ ] **HR-GEO-01｜地理角色（阻擋）**：居住地、工作場所與全國資料已分開標示。
- [ ] **HR-TIME-01｜期間語意**：月底人口、年度結構及全年薪資未被當作同一觀察期。
- [ ] **HR-UNIT-01｜單位與統計量（阻擋）**：人、%、萬元、平均數、中位數及分母可回溯。
